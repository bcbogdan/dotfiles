# Clarity Checklist

Ask only for missing items.

Required for troubleshooting:
- A minimal reproduction path with steps
- SDK type(s) and versions (e.g. Node, Python, Web)
- SuperTokens Core version
- Framework + version (e.g. Next.js, NestJS)
- Error message + stack trace
- Debug logs (redact secrets)

Helpful context:
- Hosting model (self-hosted, managed)
- DB type + version
- Deployment environment + OS
- Config snippets for SuperTokens setup
- Expected vs actual behavior

Response template:
"Thanks for the report. To proceed I need: <missing items>. If you can share <logs/versions/steps>, I can try to reproduce on a clean setup."
